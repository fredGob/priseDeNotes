# priseDeNotes

Appli de prise de notes façon Google Keep, avec des tâches à délai façon Todoist.
100 % locale et **hors ligne** : HTML + CSS + JavaScript, sans dépendance ni installation.

- Stickers (cartes) déplaçables, avec du texte, des cases à cocher et des tâches à délai en jours ouvrés (jours fériés français exclus)
- Liste de toutes les tâches à droite, triée par urgence (J-x, retard)
- Étiquettes, filtre, recherche, couleurs, archives, suppression annulable
- Heure, semaine, éphéméride
- Export / import JSON

## Utilisation
Double-cliquer sur `index.html` (Edge / Chrome). Guide complet : [LISEZMOI.md](LISEZMOI.md).

## Tests
Ouvrir `tests/tests.html` dans le navigateur → bandeau vert.
